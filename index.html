      🎙️ Siri mode
      Once it's set up, say "Hey Siri, SkyCast weather" and Siri reads you the forecast for your city. Plain "what's the weather" always goes to Apple's own Weather app, so SkyCast uses its own phrase.
      Your forecast link
      Open the Weather tab first so SkyCast can make your link.
      Set it up once (about 2 minutes, iPhone or iPad)
      1. Open the Shortcuts app and tap + to make a new shortcut. Tap its name at the top and call it SkyCast weather.
      2. Add the action Get Contents of URL and paste your forecast link into it.
      3. Add Get Dictionary Value. Set it to get the value for the key properties.
      4. Add another Get Dictionary Value for the key periods.
      5. Add Get Item from List and leave it on First Item.
      6. Add one more Get Dictionary Value for the key detailedForecast.
      7. Add Speak Text. Tap Done.
      8. Try it: "Hey Siri, SkyCast weather."
      The link is for the city you're looking at right now. If you move or want a different city, pick it in SkyCast, then copy the new link into your shortcut.
